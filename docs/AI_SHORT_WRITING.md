# 简短描述生成考核单

职工无需登录。填写并记住班组、姓名，选择检查日期、班次和被考核公司，只输入现场问题。
点击「AI整理考核单」，查看整理后的正文和后台核算金额，再点击「生成考核单」。
缺少条件时保留完整AI正文与整改草稿，一次展示一个关键问题。已知条件回答由后端本地重算，不再次调用AI。
正式出单无需设备授权或主管审批；后台主管、管理员可上传 Word 直接发布制度。自动生成仍须按原文核对现场事实；金额由本地规则计算。模型无法确认其他条件时，页面给出可回答的事实核对项，不必重复调用 AI。
正文可编辑：标点及整改措辞修改本地确认重签；事实、否定表达、条款、数量或金额改变必须重新整理。计价字段只读。

未确定计价时保留问题初稿，并显示具体补问和符合实际才可点击的补充选项；未就绪初稿不能生成正式文书。

## 本地配置和启动

密钥只放在被Git忽略的 `.tmp/local-preview/deepseek.env`，不在浏览器或源码中。
`DEEPSEEK_MODEL=deepseek-flash`，API请求关闭thinking，最大输出默认900 token，可配置；截断不自动重试收费。
运行 `powershell -File scripts/start-local-api.ps1` 启动后端，另运行 `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`。

无登录AI调用有设备、来源IP及全局频率限制，并发1、有限排队；每设备12次/小时，全局60次/小时。相同请求有TTL缓存及在途合并。
整理结果有效期2小时，签名绑定设备、日期、班次、公司、正文、数量和金额。
改变日期、班次或公司需要重新整理；转换失败的重试仍使用同一归档请求。
本地后端重启会轮换临时JWT密钥，尚未保存的AI结果需要重新整理。
