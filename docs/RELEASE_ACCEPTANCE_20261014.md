## 本轮修复

1. 修复手机首页 `/api/quick/config` 未定义 payload 导致的 500，当前制度按北京时间当天选取。
2. 主管和管理员直接发布、下载及恢复制度，保持普通职工免登录、免设备登记、免主管审批。后台移除旧设备登记展示。
3. 发布与恢复统一使用跨进程文件锁、原始前态、持久化操作日记和数据库审计标记。发布/恢复审计失败时恢复确切前态；中断后按审计是否已提交决定恢复前态或已提交态，不再盲目取最后一个版本。
4. 恢复制度从恢复当天起生效，历史日期仍按当时版本选择；旧文书不重建。中文版本名原件下载采用稳定 ASCII 文件名，避免 HTTP 头编码错误。
5. Word 解析保留重复段落、全部非空源正文块、表格行及附件定位，新增前后规则 ID/原文哈希/金额变更预览。自动编号仍需结合原始 Word 核对。
6. 新增保守的本地简明金额解析：完整短句、单一整数金额、固定金额/每次/每件。启用前与旧版比较；旧条款修改金额或条件、区间、组合、时间条件、表格及附件保持人工核定。原有 8 条原文一致的核准规则可继承。
7. AI 结果和签名核对同一制度摘要，防止调用期间换制度后，旧候选 ID 被套入新金额。上传/恢复后当前查询目录刷新，其他后台标签页重新聚焦时刷新。
8. 修复 AiComposer 首次挂载无条件清除恢复签名；临时签名恢复绑定设备、班组姓名及事实/计费上下文，不写永久 localStorage。
9. 真实 DeepSeek 抽样发现模型虽匹配条款但未确认语义条件时出现不可回答的卡点，已补充明确的原文事实核对项。选择条款仍保留 missingFields/conditionsSatisfied，只有使用者显式核对后才继续；明确否定事实仍不能被覆盖。整个补充过程本地执行，不重复调用 AI。
10. 完善人工正文金额校验，覆盖中文大小写、圆整、全角数字及角分/分隔符歧义；矛盾金额不能正式生成。
11. 交付源码暂存放在项目目录外；开发服务忽略输出、临时目录和虚拟环境，避免打包 ZIP 的文件监听冲突及复制源码造成重复测试发现。

## 剩余风险与上线阻塞

1. **Docker/PostgreSQL 运行未验收**：Docker Desktop 报 `dockerInference` 残留通信套接字错误。自动审批拒绝清理该系统套接字，未执行清理或重置。尝试独立 PostgreSQL 二进制下载也因网络吞吐不足中止，没有执行数据库。不得把 DDL 编译或 SQLite 通过说成 PostgreSQL 通过。
2. **生产 Linux 视觉未验收**：本次看图是 Windows 便携 LibreOffice。Linux Noto 字体替代宋体后的折行、420 字边界和签批区仍必须在实际镜像复验；字体不同可能改变单页容量。
3. **生产备份恢复/重启持久化未演练**：发布日记中断恢复属于模拟故障测试；真实 API 强杀、多进程 Linux 锁、容器重建、磁盘满和 PostgreSQL 成组恢复仍需实测。
4. **制度来源需确认**：包内为 20260819 原件及 260701 历史原件；未提供交接中提及的 20260825 版。条目 319→193 是解析分段不同，不能视为已经证明无缺失。原 Word 全部保留，预览差异须业务核对；多级自动编号、嵌套表格、文本框/脚注中的业务条款仍需针对实际文档补充样本。
5. **计费不是全覆盖**：组合、区间、金额修改、附件等仍人工核定；模型语义不确定时仍需一次明确的事实核对。中文金额校验覆盖常用表达，不是任意自然语言算式或附件多笔账目的完整解析器。
6. **手机实机分享未验收**：浏览器已准备真实 PNG/PDF，但没有实际在微信/QQ群发送，也没有验收所有手机系统/DPI。姓名自报、共享浏览器和清除本机凭证的边界仍存在。
7. **单 Worker 边界**：限流、AI 缓存和文书队列为进程内状态，重启会清空，不能通过增加 Worker 直接扩容；生产可信代理和真实 20 职工负载仍需验证。
